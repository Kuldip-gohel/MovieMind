# Movie catalog

MovieMind joins the TMDB 5000 movie and credit records to its original model by TMDB movie ID. The model has 4,806 rows representing 4,800 distinct movies. The bundled snapshot includes the original languages, release dates, genres, descriptions, cast, directors and keywords used for offline prompt matching. Poster paths are historical metadata. Live TMDB details take priority when a credential is configured.

- [TMDB 5000 Movie Dataset](https://www.kaggle.com/datasets/tmdb/tmdb-movie-metadata)
- [The Movies Dataset](https://www.kaggle.com/datasets/rounakbanik/the-movies-dataset)
- [TMDB Top Rated Movies](https://www.kaggle.com/datasets/mdnafizekbal/tmdb-top-rated-movies-dataset-10000-movies) and [TMDB Movie Metadata 10K](https://www.kaggle.com/datasets/vaibhavthota/tmdb-movie-metadata-dataset-10k-movies) supply updated poster paths. Selected posters were checked against the public TMDB movie pages.
- [TMDB API documentation](https://developer.themoviedb.org/docs/getting-started)

This product uses the TMDB API but is not endorsed or certified by TMDB.
